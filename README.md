# dokumenter-flat

Skill Claude untuk bikin video explainer YouTube gaya **dokumenter animasi flat** (16:9 + potongan Shorts 9:16), bahasa Indonesia, niche ekonomi & kebiasaan.

## Isi

| File | Fungsi |
|---|---|
| `skills/dokumenter-flat/SKILL.md` | Alur kerja end to end: topik → riset → naskah → suara → storyboard → Remotion → paket YouTube → 3 Shorts |
| `skills/dokumenter-flat/MOTION_PHYSICS_EASING_BIBLE.md` | Aturan gerak lengkap (easing, overlap, stagger, kamera, motion blur) |
| `skills/explainer-motion-graphic/SKILL.md` | Gaya explainer kertas + set ruang + objek raksasa + gerak fisik, tanpa subtitle |
| `projects/gaji-5-juta-tanggal-10/` | Contoh proyek lengkap: kode Remotion, aset, suara, alignment, render final |

Bekerja bareng skill `youtube-agent` (riset topik, naskah, judul, SEO, chapters, Shorts).

## Pasang

```bash
git clone https://github.com/Sumanto0e/dokumenter-flat.git
cp -r dokumenter-flat/skills/dokumenter-flat ~/.claude/skills/
```

Lalu: *"pakai dokumenter-flat, topik: kenapa gaji cepat habis"*.
